# Super Mario World móvil

Sitio móvil de EmulatorJS preparado para ejecutar **Super Mario World de Super Nintendo** con controles táctiles, guardado persistente, menú de estados y avance rápido 2×.

## ROM requerida

Coloca en la raíz del repositorio tu ROM de Super Mario World y renómbrala exactamente:

`Super-Mario-World.sfc`

Se recomienda una ROM SNES sin cabecera en formato `.sfc`. El sitio no incluye la ROM.

## Publicación

Activa GitHub Pages en **Settings → Pages**, seleccionando la rama `main` y la carpeta raíz `/`.

El sitio abrirá el juego automáticamente. En navegadores móviles, el audio puede empezar con el primer toque por la política de reproducción automática del sistema.

## Controles

- Cruceta, A, B, X, Y, L, R, Start y Select.
- `2×`: un toque activa el avance rápido; otro vuelve a velocidad normal.
- Menú hamburguesa: guardar/cargar estado, ajustes y pantalla completa.
